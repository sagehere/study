# Course Authoring Templates

These four templates encode the tested pedagogical shapes supported by the current engine:

- `procedural`: diagnose → guided → repair → formalize → independent → transfer.
- `concept-representation`: diagnose → contrast → repair → representation → formalize → transfer.
- `quantity-relation`: diagnose → model → repair → inverse → formalize → composite → transfer.
- `boundary-concept`: locate → boundary → repair → formalize → reverse → transfer.

Templates are scaffolds, not publishable lessons. Generated packages start with `meta.authoringStatus = "draft"` and TODO text. Authors or future Skills must replace placeholders with textbook-grounded objectives, misconceptions, choices, hints, renderer declarations, transfer evidence and review logic before setting status to `ready`.
